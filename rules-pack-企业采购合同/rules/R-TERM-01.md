# 规则 R-TERM-01 期限、变更与解除

- 规则编码：R-TERM-01
- 规则分类：合同期限
- 判定方式：rule_check（LLM 按明确要件核验）
- 严重度：中
- 状态：active
- 是否隐性：否

## 审核维度（风险信号 / 合规要件）
1. 合同期限：风险信号——无有效期/履行期限，或起止不明；合规要件——明确合同生效日、履行/服务期限、到期日。
2. 变更条件：风险信号——变更无书面/确认程序，或一方可单方变更；合规要件——变更须双方书面协商一致。
3. 解除条件：风险信号——无法定/约定解除情形，或仅一方有解除权；合规要件——约定解除情形、通知程序，双方解除权对等。
4. 解除后结算与善后：风险信号——解除后已履行部分、款项、资料、数据如何处理不明；合规要件——明确解除后的结算、资料/数据移交、保密与违约责任存续。

## 审核提示词（给 LLM）
你是资深企业法务，审查采购合同「期限、变更与解除」。仅依据合同原文核验：合同期限是否明确、变更是否须书面协商一致、解除条件与双方解除权是否清晰、解除后结算与善后是否约定。
判定标准：四项要件齐备且对等即通过；期限缺失、单方变更/解除、解除后无善后约定任一即命中。
输出严格 JSON：`{rule_id, hit, severity, location, quote, problem, suggestion}`。
- `quote` 须为原文可逐字检索摘录；要件缺失在 problem 注明"未约定"。
- 防幻觉，不得编造；无法判定输出 hit=false 且 need_human=true。

## 命中输出模板
- 问题：{期限/变更/解除/解除后善后中缺失或不对等的具体问题}
- 定位：{章节} {原文摘录}
- 建议：{明确有效期与履行期限；变更须书面协商一致；约定对等解除情形与通知；补解除后结算、资料数据移交与条款存续}
