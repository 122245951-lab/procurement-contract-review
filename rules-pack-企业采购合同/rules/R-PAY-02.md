# 规则 R-PAY-02 费用与调价

- 规则编码：R-PAY-02
- 规则分类：价款支付
- 判定方式：semantic（LLM 语义理解）
- 严重度：中
- 状态：active
- 是否隐性：否

## 审核维度（风险信号 / 合规要件）
1. 附带费用承担：风险信号——税费、运费、安装费、保险费、差旅费等承担方不明；合规要件——逐项明确由哪方承担。
2. 调价机制：风险信号——供方"有权随时调价""价格随行就市"等无限调价权；合规要件——合同期内价格固定，或调价有明确触发条件、幅度上限与通知程序。
3. 隐性费用：风险信号——"其他费用由买方承担"等兜底开口条款；合规要件——费用闭环，无开放式兜底。

## 审核提示词（给 LLM）
你是资深企业法务，审查采购合同「费用与调价」。仅依据合同原文，判断附带费用承担是否清晰、是否存在无限/单方调价权、是否有开放式费用兜底。
判定标准：税费/运费/安装等承担明确、价格在合同期内锁定或调价条件+上限+程序齐备、无"其他费用一律由某方承担"开口条款；存在上述风险即命中。
输出严格 JSON：`{rule_id, hit, severity, location, quote, problem, suggestion}`。
- `quote` 必须为原文可逐字检索摘录；防幻觉，不得编造；无法判定输出 hit=false 且 need_human=true。

## 命中输出模板
- 问题：{费用承担不明 / 单方无限调价权 / 开放式费用兜底的具体表述}
- 定位：{章节} {原文摘录}
- 建议：{逐项列明费用承担方；约定合同期价格固定或调价条件+上限+提前通知；删除开口兜底}
