# 规则 R-DELIV-01 交付与验收

- 规则编码：R-DELIV-01
- 规则分类：交付验收
- 判定方式：rule_check（LLM 按明确要件核验）
- 严重度：高
- 状态：active
- 是否隐性：否

## 审核维度（风险信号 / 合规要件）
1. 交付时间与地点：风险信号——无交付期限/地点，或"尽快交付"；合规要件——明确交付日期/期限、交付地点与方式。
2. 验收标准：风险信号——仅"验收合格"而无标准；合规要件——援引国标/行标或约定具体技术参数、功能清单。
3. 验收流程与期限：风险信号——无验收程序、无异议期限；合规要件——约定验收步骤、验收期、逾期不答复视为合格/不合格的处理。
4. 不合格处理：风险信号——验收不合格无救济；合规要件——明确限期整改、换货、退货、扣款或解除权。
5. 验收凭证：风险信号——无签收/验收单；合规要件——约定书面验收凭证作为付款触发。

## 审核提示词（给 LLM）
你是资深企业法务，审查采购合同「交付与验收」。仅依据合同原文核验上述五项要件。
判定标准：交付时间地点明确、验收标准具体可衡量、验收流程与期限清晰、不合格处理可执行、有验收凭证约定；任一缺失即命中。
输出严格 JSON：`{rule_id, hit, severity, location, quote, problem, suggestion}`。
- `quote` 须为原文可逐字检索摘录；要件缺失时 problem 注明"未约定"。
- 注意：付款条款若以"验收合格"为前提但本合同无验收标准，属于高风险，应在 suggestion 中明确指出付款触发条件落空。
- 防幻觉，不得编造；无法判定输出 hit=false 且 need_human=true。

## 命中输出模板
- 问题：{交付时间地点/验收标准/验收期限/不合格处理/凭证中缺失或不可执行的具体问题}
- 定位：{章节} {原文摘录}
- 建议：{明确交付期限地点；约定可衡量验收标准；补验收流程与异议期；约定不合格救济与书面验收单}
