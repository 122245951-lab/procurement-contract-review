# 规则 R-WARR-01 质量保证与售后

- 规则编码：R-WARR-01
- 规则分类：质量售后
- 判定方式：rule_check（LLM 按明确要件核验）
- 严重度：中
- 状态：active
- 是否隐性：否

## 审核维度（风险信号 / 合规要件）
1. 质保期：风险信号——无质保期或"合理期限"模糊表述；合规要件——明确质保/缺陷责任期起止（通常自验收合格之日起算）。
2. 质保范围：风险信号——质保范围不清，易生争议；合规要件——明确质保覆盖的部件/功能/服务与除外情形。
3. 售后响应：风险信号——无响应时限；合规要件——约定故障响应/到场/修复时限（如 4 小时响应、24 小时修复）。
4. 保修与退换责任：风险信号——质保期内缺陷责任不明；合规要件——明确免费维修/更换/退货及费用承担。

## 审核提示词（给 LLM）
你是资深企业法务，审查采购合同「质量保证与售后」。仅依据合同原文核验质保期、质保范围、售后响应时限、保修与退换责任四项要件。
判定标准：四项要件明确可执行即通过；质保期缺失/模糊、响应无时限、缺陷责任不清即命中。
输出严格 JSON：`{rule_id, hit, severity, location, quote, problem, suggestion}`。
- `quote` 须为原文可逐字检索摘录；要件缺失在 problem 注明"未约定"。
- 防幻觉，不得编造；无法判定输出 hit=false 且 need_human=true。

## 命中输出模板
- 问题：{质保期/范围/响应/退换责任中缺失或模糊的具体问题}
- 定位：{章节} {原文摘录}
- 建议：{明确质保期起止与范围；约定响应与修复时限；明确质保期内免费维修/更换及费用承担}
