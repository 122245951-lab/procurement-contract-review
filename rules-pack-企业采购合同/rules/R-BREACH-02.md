# 规则 R-BREACH-02 不可抗力与免责

- 规则编码：R-BREACH-02
- 规则分类：违约责任
- 判定方式：rule_check（LLM 按明确要件核验）
- 严重度：中
- 状态：active
- 是否隐性：否

## 审核维度（风险信号 / 合规要件）
1. 不可抗力条款有无：风险信号——完全没有不可抗力条款；合规要件——设专门条款定义不可抗力。
2. 定义宽窄：风险信号——把"政策变化、市场波动、原材料涨价"等正常商业风险纳入不可抗力；合规要件——限于不能预见、不能避免且不能克服的客观情况（自然灾害、战争、疫情管控等）。
3. 通知与举证：风险信号——无通知时限与证明要求；合规要件——受影响方应在合理期限内通知并提供证明。
4. 后果分担：风险信号——长期不能履行无处理；合规要件——约定部分/全部免责范围、延期履行、超期解除及费用分担。

## 审核提示词（给 LLM）
你是资深企业法务，审查采购合同「不可抗力与免责」。仅依据合同原文核验：是否有不可抗力条款、定义是否过宽（纳入正常商业风险）、通知与举证是否明确、后果分担与超期处理是否清晰。
判定标准：缺条款、定义过宽、无通知举证、无后果分担任一即命中。
输出严格 JSON：`{rule_id, hit, severity, location, quote, problem, suggestion}`。
- `quote` 须为原文可逐字检索摘录；要件缺失在 problem 注明"未约定"。
- 防幻觉，不得编造；无法判定输出 hit=false 且 need_human=true。

## 命中输出模板
- 问题：{缺不可抗力条款/定义过宽/无通知举证/无后果分担的具体问题}
- 定位：{章节} {原文摘录}
- 建议：{增设不可抗力条款；将商业风险剔除出定义；约定通知时限与证明；明确免责范围与超期解除}
