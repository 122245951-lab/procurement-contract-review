# 规则 R-DISP-01 争议解决与送达

- 规则编码：R-DISP-01
- 规则分类：争议解决
- 判定方式：semantic（LLM 语义理解）
- 严重度：中
- 状态：active
- 是否隐性：否

## 审核维度（风险信号 / 合规要件）
1. 争议方式唯一明确：风险信号——既约定仲裁又约定诉讼（或约定"可仲裁可诉讼"），导致条款无效/不确定；合规要件——诉讼与仲裁二选一，表述唯一明确。
2. 管辖有实际联系：风险信号——约定与争议无实际联系的法院，或"由供方所在地法院管辖"单方便利；合规要件——约定被告住所地、合同履行地、签订地、标的物所在地等与争议有实际联系地点的法院。
3. 仲裁机构具体：风险信号——仅"提交仲裁"而无明确仲裁机构，仲裁条款无效；合规要件——写明具体仲裁委员会名称（如"XX仲裁委员会"）。
4. 适用法律：风险信号——涉外合同未约定适用法律；合规要件——（涉涉外因素时）明确适用中华人民共和国法律。
5. 送达条款：风险信号——无送达地址/电子送达约定，诉讼文书送达难；合规要件——约定送达地址、电子邮箱及"按该地址送达即视为送达"。

## 审核提示词（给 LLM）
你是资深企业法务，审查采购合同「争议解决与送达」。仅依据合同原文判断上述五维。
判定标准：争议方式唯一、管辖法院与争议有实际联系且不单方失衡、（选仲裁时）仲裁机构具体明确、涉外有适用法律、有送达条款；存在仲裁诉讼并存、仲裁机构不明、无实际联系管辖、缺送达约定任一即命中。
输出严格 JSON：`{rule_id, hit, severity, location, quote, problem, suggestion}`。
- `quote` 须为原文可逐字检索摘录；要件缺失在 problem 注明"未约定"。
- 防幻觉，不得编造；无法判定输出 hit=false 且 need_human=true。

## 命中输出模板
- 问题：{仲裁诉讼并存/管辖无联系或失衡/仲裁机构不明/缺适用法律/缺送达条款的具体问题}
- 定位：{章节} {原文摘录}
- 建议：{诉讼仲裁二选一；约定有实际联系且对等的管辖法院；仲裁须写明具体仲裁委；涉外补适用法律；增加送达地址与电子送达条款}
